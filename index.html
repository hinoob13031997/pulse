Как устроена эта панель — что где искать
  • Платежи ОДВ — поступившие деньги только по закреплённым за ОДВ сотрудникам. Все платежи — то же самое, но без этого фильтра, по всем.
  • Журнал взаимодействия — звонки и их результат по дням/операторам, построчно.
  • Воронка — отдельная вкладка для файла «Воронка»: сводка по звонкам (сколько всего, сколько дозвонились — RC, сколько дали обещание оплаты — PTP) по группам, за текущий и предыдущий период. Это не строки журнала и никак не увеличивает число записей на вкладке «Журнал взаимодействия».
  • Портфель ОДВ / Портфель весь — состояние дел по договорам: статусы, возраст дела (сколько дней с даты возбуждения ИП), кто ведёт.
  • Цифры и графики на этой странице считаются из того, что уже загружено в соответствующие вкладки — здесь ничего отдельно загружать не нужно.
  • «Заметные изменения» ниже — автоматическое сравнение последней загрузки с предыдущей по каждой вкладке: резкий рост или падение видно сразу, искать вручную не нужно.
  • Кнопка «⭳ Скачать в Excel» есть в каждой вкладке — выгружает только её данные. Кнопка «⭳ Весь дашборд в Excel» в шапке — выгружает сразу все 5 вкладок в один файл, каждая на своём листе. «🖶 Печать / PDF» печатает текущую открытую вкладку, PDF сохраняется прямо из диалога печати.
  • «⇅ Обмен данными» в шапке — всё хранится только в этом браузере; эта кнопка выгружает все загруженные данные и историю одним файлом, чтобы передать коллеге, а он загрузит его кнопкой «⇊ Загрузить» на своём компьютере.
  • Поиск ниже ищет и по клиенту, и по сотруднику — сразу по всем 5 вкладкам.

Нет готовой сводной выгрузки? Загрузите (или вставьте) обычный сырой файл по звонкам — построчно, как в «Журнале взаимодействия», с колонками оператора и результата звонка. Дашборд сам найдёт нужные колонки, разобьёт на текущий/предыдущий период по дате и построит воронку по группам сотрудников.

Настройки распределения

Сотрудник Доля Цель: кол-во Цель: сумма ₽ Активен
«Доля» используется в методах «По сумме долга»/«По количеству». «Цель: кол-во» и «Цель: сумма» — только в методе «По целям»: кол-во — это жёсткий лимит на сотрудника (чтобы не закинуть 200 мелких договоров), сумма — то, к чему алгоритм стремится в пределах этого лимита.
